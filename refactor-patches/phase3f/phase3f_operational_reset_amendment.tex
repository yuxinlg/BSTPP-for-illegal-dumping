artifact contracts, and a resumption point that is not the phase
boundary}\label{a-54}}

\textbf{Opened 2026-08-07 against \texttt{c4e069f}.}
\textbf{Class DOC/process, with model/API decisions explicitly named in
D-54--D-58.} Establishes D-53--D-62. Adopts
\texttt{docs/phase3f\_completion\_manifest.yaml},
\texttt{docs/phase3f\_execution\_protocol.md},

\paragraph{The number, first, because the first draft got it wrong.}

This entry was drafted as A-53 against tip \texttt{db55ee1}. \textbf{A-53 was
taken while it was being drafted}, by \texttt{c4e069f} --- WP2.8, CI-7 enforced
at the \texttt{sp\_var\_mu} site, class SC/API. That commit touches
\texttt{bstpp/main.py} and adds \texttt{tests/test\_ci7\_sp\_var\_mu.py}, so it
is \emph{not} the documentation-only descendant the draft's own precondition
permitted, and \texttt{results/\allowbreak{}\_a53\_*} is already populated with
twenty of its gate captures. \textbf{Both errors would have been destructive
had the draft been installed}: the amendment number would have collided with a
published entry, and the gate outputs would have overwritten a production
commit's evidence --- the A-40/A-41 failure this register has already named
once. The draft is superseded here rather than repaired in place, and its
baseline moves from \texttt{db55ee1} to \texttt{c4e069f}.

\paragraph{Why this amendment exists.}

At \texttt{c4e069f}, Phase~3f had a strong regression foundation and its
original architectural outcome was substantially unbuilt. \textbf{The sharpest
measurement is not the commit count.} Since WP2 opened at A-45 there have been
nine amendments, three of which touch \texttt{bstpp/}, and \textbf{zero of the
five frozen configuration objects have been created}: \texttt{NumericalConfig}
exists and landed before WP2 opened; \texttt{ModelConfig} and
\texttt{PriorConfig} are enumerated and absent; \texttt{PartitionDecoderConfig}
and \texttt{InferenceRunConfig} are unstarted. \texttt{main.py} still owns the
public wrappers, simulation, metrics, nine plotting methods, and 176
\texttt{self.args} references. Meanwhile current truth was spread across the
register, an outline, a dependency graph, a seam-set file, ten work-package
entries, findings, captures, and \texttt{AGENTS.md}. The result was high local
traceability and weak global executability.

\paragraph{The generator, named, because renaming the authority does not remove
it.}

Each of the nine amendments was individually justified, and most were justified
by an \emph{apparatus obligation rather than a deliverable}: A-51 existed
because A-49 left anchors; A-52 existed because A-51 silently edited landed
text; A-53 existed because A-52's seam-set declaration made an unenforcing site
visible. \textbf{The mechanism is that documents which cite the register join
the populations of the instruments that sweep the register}, and each sweep can
produce a finding that requires another document. A tenth document that cites
the register would extend the cycle, not end it. \textbf{Hence two structural
choices rather than one more authority claim}: the manifest is YAML and sits
outside the declared \texttt{.tex}/\texttt{.md} gate populations by
construction (D-53), and the two technical contracts carry no register IDs at
all (D-61). What remains inside the prose gates is the register itself, the
execution protocol, and \texttt{AGENTS.md} --- three files, which is what those
instruments were built for.

\paragraph{D-53 --- one operational authority.}

The manifest is authoritative for present-tense execution state. A commit that
changes a deliverable's scope, status, dependency, blocker, cycle count, or
exit gate changes the manifest in the same commit. Older planning files remain
readable and citable, with a banner pointing to the manifest, but are not
synchronized as parallel task trackers. \texttt{AGENTS.md} retains stable
engineering rules and points to the manifest instead of reproducing its mutable
status narrative.

\paragraph{D-54 --- OP-28 answered, and answered at no cost.}

The package intends exact clipped-domain area weighting for its explicit
\texttt{'domain\_area'} convenience. \textbf{That is already what it does.}
\texttt{validate\_standardize\_cov} accepts \texttt{None} and
\texttt{'domain\_area'} and nothing else; \texttt{attach\_covariate\_partitions}
builds its weights from the area of \texttt{cov\_support}, the covariate layer
clipped to the domain, and keeps zero-area rows so covariate indexing is
unchanged. The decision therefore settles intent without a code change, which
makes it the cheapest item in this amendment and the reason it should land
first if this amendment is ever split. It is not a cross-site normalization
scheme: analysts comparing coefficients across sites use an externally fixed
reference and pass \texttt{None}. The measured A-41 difference from legacy
\texttt{True} remains on the record and is not reinterpreted as numerical
noise. This closes G-B; the earlier API narrowing that rejected booleans remains
the SC/API change already recorded.

\paragraph{D-55 --- WP8 ownership without public churn.}

\texttt{spatial\_cov\_crs} describes input data and therefore belongs to
\texttt{ModelData}. \texttt{data\_contracts} selects an enforcement policy and
therefore belongs to \texttt{InferenceRunConfig}. Relocation changes canonical
ownership, not the public constructor contract. In particular, BSTPP still
requires an explicit CRS for plain tabular covariates paired with a CRS-bearing
domain and never makes them look valid by copying the domain CRS.

\paragraph{D-56 --- decoder identity, and which artifacts it covers.}

Partition sizes are configuration constrained in practice by the trained
decoder grids, and the spatial gain is a convention paired with the trained
decoder rather than a derived formula. The contract records exactly those
executable facts. File-backed artifacts use content identity; custom decoders
use declared identity because hashing a callable would be false
reproducibility. \textbf{Scope is stated because the directory does not state
it}: \texttt{bstpp/decoders/} ships nine files and \texttt{\_load\_decoder}
reaches three. Naming the three keeps WP7 from discovering the other six as a
corrective cycle. The digest is computable without new machinery ---
\texttt{\_load\_decoder} already holds the raw bytes from
\texttt{pkgutil.get\_data} before \texttt{pickle.loads}, so hashing before
deserialization is a two-line change at one site. The seasonal sidecar's
unknown training facts remain \texttt{UNKNOWN}. A required compatibility fact
--- role, shape, partition, flattening, or gain --- may not be made unknown.

\paragraph{D-57 --- results schema v1, and the gate that could not see itself.}

The old result file is a pickle of \texttt{samples} and optional opaque
inference state. It cannot establish which events, domain, decoder, support,
cutoffs, standardization, or config produced the samples. Schema~v1 keeps the
trusted-pickle container to bound Phase~3 work, but wraps it in a versioned,
\texttt{args}-independent record with transactional validation and attachment.

\textbf{The strict G2 xfail is itself an instance of the apparatus class A-52
enumerated.} It asserts \texttt{blob["cutoff\_provenance"]} at the envelope's
top level. Schema~v1 places that record at \texttt{excitation.cutoffs}. A WP9
commit implementing the contract exactly and completely would therefore leave
the xfail \emph{still xfailing}, and the gate meant to certify G2 would report
nothing when G2 was satisfied. Naming it here, rather than discovering it in
the WP9 commit, is the difference between a planned test edit and a corrective
cycle.

\paragraph{D-58 --- the historical external consumer.}

The old analysis reference to
\texttt{bstpp.cox\_hawkes\_shared.Cox\_Hawkes\_Shared} creates no supported
surface: the module is absent, the focused analysis does not use it, and the
repository cannot verify code it does not contain. No inventory, migration
mapping, vendoring, or WP10 block is created for it.

it amends by name.}

Artifact/interface work lands decoder identity, metadata ownership, and results
schema before the final cutover removes \texttt{args}, delegates plotting, and
thins the model wrappers. Per-commit verification is targeted plus the fast
lane; full lanes, both pin baselines and affected smokes run at slice
boundaries. The exact trigger matrix and stop rule live in the execution
protocol.

\textbf{D-52 requires that retroactive reach be enumerated and not asserted, so

\paragraph{D-61 --- contracts do not carry lineage.}

A specification that cites the register must be swept whenever the register
moves, and a reader of the specification must hold the register open to
understand it. Both costs are avoidable and neither buys correctness: the
decoder contract's authority comes from being adopted here, not from repeating
that fact inside itself. Provenance lives in exactly two places --- this
amendment and the manifest's \texttt{settled\_decisions} block. Process
documents are exempt, because for them the governing decision \emph{is} the
content.

\paragraph{D-62 --- the resumption point, and why it is not a phase boundary.}

The stated purpose of finishing Phase~3f is to resume the analysis. Those are
not the same commit. \textbf{Everything the analysis consumes is in place at
the S3 boundary}: typed configuration, consolidated runtime ownership, a
decoder contract that fails before inference rather than after it, and a
results envelope that records which events, domain, decoder, cutoffs, and
standardization produced a posterior. \textbf{Everything S4 does is invisible
from outside the package} --- \texttt{self.args} is internal state, plotting
delegation preserves \texttt{model.plot\_*}, and thin wrappers preserve the two
public classes. A downstream result computed at the S3 boundary and recomputed
after S4 must be identical, or S4 was misclassified.

\textbf{So the milestone is named and the phase boundary is not moved.} Phase~3f
still closes at S4 and Phase~3g still owns the SBC run, the equation-to-code
documentation, and the \texttt{cbg-park-seasonal} confirmation. What changes is
that a slipped S4 no longer holds the science. \textbf{This is a scheduling
decision and not a quality concession}: the resumption commit carries the same
pin baselines, both test lanes, all three family smokes, and the schema-v1 and
decoder-contract negative tests that Phase~3f exit requires. It omits only the
gates that exist to certify internal structure.

\paragraph{Responsibility completeness.}

The manifest maps every original \S10.f responsibility to exactly one
completion owner: WP2 owns model/prior config; WP3 partition-decoder and run
config plus fitting RNG; WP4 prepared state, partition products and the
likelihood boundary; WP5 shared support/mass/cutoff atoms; WP6 mutators and
membership; WP7 decoder contract; WP8 input metadata; WP9 results I/O; WP10
plotting delegation, thin wrappers, simulation RNG and \texttt{args} removal.
A package cannot close by completing a narrower entry while leaving its
original responsibility unmapped.

\paragraph{One correction to the public surface as previously described.}

Earlier planning text names ``Hawkes, LGCP, and Cox--Hawkes public classes.''
\textbf{There are two public classes}, \texttt{Hawkes\_Model} and
\texttt{LGCP\_Model}; Cox--Hawkes is \texttt{Hawkes\_Model(cox\_background=True)}.
The distinction matters only where a deliverable is stated: WP10 thins
\emph{two} classes, and the end-to-end smokes cover \emph{three}
configurations. Stated so the WP10 exit gate does not name a class that cannot
be produced.

\paragraph{Phase boundary and exit.}

Phase~3f closes at one named commit satisfying the finite manifest predicate.
Phase~3g still owns the new Cox--Hawkes Stage~3 SBC run at $R=200$ at the final
Phase~3 tip, final equation-to-code and implementation documentation, and the

amplitudes, arbitrary standardization weights, city-scale inference, new
reporting/computation classes, the historical shared consumer, validation of the
six out-of-contract decoder artifacts, and further general audit loops remain
outside Phase~3f.
