TWO THINGS THE GREP FOUND THAT THE QUESTION DID NOT ASK FOR:
 1. All six live calls pass standardize_cov=True, and booleans have
    been rejected on `refactor` since OP-3/OP-4. On origin/main the
    parameter DEFAULTS to True and is a plain flag (unweighted
    (X-mean)/sd); on refactor it defaults to None and 'domain_area' is
    AREA-WEIGHTED. So these six already break, for an older and
    already-decided reason, and a migrating user must change the value
    AND accept different numbers. A break we own and shipped.
 2. They subclass bstpp.cox_hawkes_shared.Cox_Hawkes_Shared, a module
    THIS FORK DOES NOT HAVE; their bstpp/ is vendored and untracked.
    The surface we own for them is Point_Process_Model.__init__,
    which their subclass inherits.
